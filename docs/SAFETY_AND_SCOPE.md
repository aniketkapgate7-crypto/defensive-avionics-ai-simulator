# Safety and Scope

This repository is a fictional, offline AI-learning environment.

## Included

- Public academic modulation-classification data
- Synthetic or properly licensed visual data
- Normalized, abstract reinforcement-learning variables
- Model evaluation and visualization
- Software-only demonstrations

## Excluded

- RF transmission, interference, or hardware control
- Real radar parameters, emitter libraries, or threat databases
- Real aircraft, weapon, navigation, or targeting interfaces
- Operational evasion procedures
- Claims that the simulator reproduces a proprietary defence system

## Communication rule

Use phrases such as “fictional scenario,” “abstract response,” and “relative
urgency.” Avoid presenting simulation outputs as validated real-world advice.
