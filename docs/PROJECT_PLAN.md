# Eight-Week Development Plan

## Week 1 — Foundation

- [ ] Create the virtual environment
- [ ] Run setup checks and tests
- [ ] Add trusted local datasets
- [ ] Produce dataset cards
- [ ] Record the first Git commit

## Week 2 — Signal baseline

- [ ] Inspect I/Q shapes and class balance
- [ ] Split data without leakage
- [ ] Train a simple baseline
- [ ] Train the 1D-CNN
- [ ] Export confusion matrix and per-SNR results

## Week 3 — Abstract simulator

- [ ] Finalize normalized observation and action contracts
- [ ] Implement deterministic scenario tests
- [ ] Implement the rule-based baseline
- [ ] Validate termination and truncation behavior

## Week 4 — RL policy

- [ ] Train PPO on at least three seeds
- [ ] Save checkpoints and evaluation logs
- [ ] Compare against the rule-based baseline
- [ ] Diagnose unstable rewards before tuning

## Week 5 — Vision dataset

- [ ] Prepare licensed or synthetic images
- [ ] Annotate and audit labels
- [ ] Create leak-free splits
- [ ] Write the vision dataset card

## Week 6 — Vision model

- [ ] Train the nano detector
- [ ] Export precision, recall, and mAP figures
- [ ] Measure FPS on the demonstration laptop
- [ ] Validate the relative urgency estimator

## Week 7 — Integration and UI

- [ ] Connect typed prediction contracts
- [ ] Build the Pygame panels
- [ ] Add deterministic demo scenarios
- [ ] Add logs, status indicators, and graceful error handling

## Week 8 — Final evaluation

- [ ] Run the fixed scenario suite
- [ ] Freeze model and configuration versions
- [ ] Finish report and presentation
- [ ] Record a backup demo video
- [ ] Rehearse a five-to-eight-minute explanation
